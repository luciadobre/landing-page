This is my personal portfolio site. I built it to show who I am and what I've worked on.

Live at: https://luciadobre.up.railway.app/

## What's in it

- A hero section with a little photo stack you can catch and hold
- My jobs and education with the story behind each one
- The tools and tech I use
- A chapters section with screenshots from stuff I've worked on
- A way to reach out if you want to work together

## Built with

- Next.js
- TypeScript
- Tailwind CSS
- Embla Carousel

## Running it locally

Install deps and start the dev server:

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

Other scripts:

```bash
npm run build   # production build
npm run start   # run the production build
npm run lint    # eslint
```
